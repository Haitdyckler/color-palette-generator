# Palette Generator & Color Wheel

Generate a 5-color palette, pick a color to see it on a color wheel with its harmonies
(complementary, split-complementary, triadic, tetradic, analogous), and double-click a color
to choose from 21 shades. Built with Next.js, TypeScript and Tailwind CSS.

## Use

- **Space** or **Generate** — new palette
- **Click** a color — select it (wheel + harmonies update)
- **Double-click** / **Enter** / **Shades** button — open 21 shades, current color in the middle
- **Esc** — close the shades
- Click any harmony swatch to copy its hex code

## Develop

```bash
npm install
npm run dev
```
